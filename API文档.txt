seedance API 文档

1. 提交视频生成任务
文生视频
POST http://token.yundashi.com/v1/video/generations
Authorization: Bearer sk-你的token
Content-Type: application/json

{
  "model": "doubao-seedance-2-0-mini",
  "prompt": "一只猫在草地上奔跑",
  "metadata": {
    "resolution": "480p",
    "ratio": "16:9",
    "mode": "text_to_video",
    "generate_audio": true,
    "n": 1
  }
}

图生视频：
{
  "model": "doubao-seedance-2-0-mini",
  "prompt": "镜头缓缓推进，画面中的人物微笑转头",
  "images": ["https://example.com/first_frame.jpg"],
  "metadata": {
    "resolution": "480p",
    "ratio": "16:9",
    "mode": "first_frame",
    "n": 1
  }
}

首尾帧生视频：
{
  "model": "doubao-seedance-2-0-mini",
  "prompt": "从白天过渡到黑夜的城市天际线",
  "images": [
    "https://example.com/first_frame.jpg",
    "https://example.com/last_frame.jpg"
  ],
  "metadata": {
    "ratio": "16:9",
    "mode": "first_last_frame",
    "n": 1
  }
}

参考生成：
{
  "model": "doubao-seedance-2-0-mini",
  "prompt": "根据参考图片、视频和音频风格生成新视频",
  "images": ["https://example.com/reference.jpg"],
  "metadata": {
    "resolution": "480p",
    "ratio": "16:9",
    "mode": "reference",
    "generate_audio": true,
    "n": 1,
    "video_urls": ["https://example.com/reference.mp4"],
    "audio_urls": ["https://example.com/reference_audio.mp3"]
  }
}


2. 查询任务状态
GET http://token.yundashi.com/v1/video/generations/{task_id}
Authorization: Bearer sk-你的token




示例：
1. 文生视频
curl -X POST http://token.yundashi.com/v1/video/generations \
  -H "Authorization: Bearer sk-你的token" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-mini",
    "prompt": "一只橘猫在草地上奔跑，阳光明媚",
    "metadata": {
      "resolution": "480p",
      "ratio": "16:9",
      "mode": "text_to_video",
      "generate_audio": true,
      "n": 1
    }
  }'


2. 图生视频
curl -X POST http://token.yundashi.com/v1/video/generations \
  -H "Authorization: Bearer sk-你的token" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-mini",
    "prompt": "镜头缓缓推进，画面中的人物微笑转头",
    "images": ["https://example.com/first_frame.jpg"],
    "metadata": {
      "resolution": "480p",
      "ratio": "16:9",
      "mode": "first_frame",
      "n": 1
    }
  }'


3. 首尾帧生视频
curl -X POST http://token.yundashi.com/v1/video/generations \
  -H "Authorization: Bearer sk-你的token" \
  -H "Content-Type: application/json" \
  -d '{

    "prompt": "从白天过渡到黑夜的城市天际线",
    "images": [

    ],
    "metadata": {
      "resolution": "480p",
      "ratio": "16:9",
      "mode": "first_last_frame",

    }
  }'

4. 参考生成

  -H "Authorization: Bearer sk-你的token" \

5. 查询任务状态
# 将 {task_id} 替换为提交任务返回的 id
curl -X GET http://token.yundashi.com/v1/video/generations/{task_id} \
  -H "Authorization: Bearer sk-你的token"
