# Agent 接入验证记录

日期：2026-11-18。分支：yunb-vip。验证对象为本次工作区修改，不代表已经部署。

## 环境与方法

- 使用临时 Go HTTP 验证入口，挂载真实 SetApiRouter、SetDeviceRouter、UserAuth、TokenAuth 与控制器；服务只监听 127.0.0.1。
- 使用 /private/tmp 中独立 SQLite、独立测试账号；SQLite 连接池为 8，验证并发行为。
- 独立 Redis 6.2.14 仅监听临时 Unix socket，不使用生产 Redis，不开启持久化。
- 浏览器会话由隔离验证入口建立；批准和撤销请求经过真实控制器与 CSRF 校验。未实际登录 GitHub/OIDC 或驱动系统浏览器。
- 通过临时夹具推进 poll_after 和 code_expires_at 验证边界，不使用 sleep 或随机压力循环。
- 模型 key 经真实 TokenAuth 校验；探测 handler 只验证鉴权成功，不访问上游、不计费，不能视为 chat/completions 真实调用验收。
- 验证脚本仅保存在临时目录，没有新增或修改仓库单元测试。
